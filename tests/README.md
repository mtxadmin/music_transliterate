# Тесты `music_transliterate`

## Запуск

```
python -m pytest tests -q
```

Без GUI-окна (тест `test_gui.py` на секунду открывает окно Tk):

```
python -m pytest tests -q -m "not gui"
```

Тесты не зависят от текущего каталога и не пишут ничего рядом со скриптами:
все файлы создаются во временных каталогах pytest.

## Что проверяется

| файл | что покрывает |
|---|---|
| `test_engine.py` | таблицы транслитерации (языки, размеры, контрольные символы), mixin и MRO, `process_filename` (включая сохранение пробелов), `detect_language`, `sanitize_filename`, `_clean_decorative_symbols`, `transliterate_text`, `has_non_ascii`, сброс состояния |
| `test_ops.py` | числовые префиксы (добавление, замена старого, `--ge-1000`, уникальность), `run_operation` (testonly / переименование / missing path), дедупликация в `output-dir`, `run_batch` (в тестовом режиме останавливается на первой ошибке, в боевом — продолжает), `get_config_path` |
| `test_cli.py` | точка входа отдельным процессом: `--help`, коды возврата, `--testonly` (в т.ч. остановка на первой ошибке), `--only-transliterate`, `--only-prefixes`, `--recursive`, `--output-dir`, `--ge-1000`, конфликты имён, неизвестный аргумент |
| `test_layout.py` | состав файлов, UTF-8 BOM + CRLF, отсутствие tkinter/yaml в движке, слои зависимостей (`tables ← core ← ops ← entry`), отсутствие дублей определений, импорт модулей из `public/`, API точки входа |
| `test_gui.py` | создание `App()`, `withdraw()`/`update()`/`destroy()` без `mainloop` (маркер `gui`, пропускается без tkinter или дисплея) |

## Особенности

- **Пробелы в именах сохраняются.** `_clean_decorative_symbols` оставляет
  пробельные символы (категория `Zs`), повторные схлопываются в один,
  по краям обрезаются; неразрывный пробел превращается в обычный, а
  табуляция и прочие управляющие символы (`Cc`) вырезаются. Поведение
  закреплено в `CLEAN_CASES` и `NAMES_CASES`.
- **Тестовый режим останавливается на первой ошибке.** Кнопка
  «Тестировать источники(и)» и `--testonly`: при первой же ошибке (нет
  папки, не удалось обработать имя, конфликт имён) проверка прерывается,
  остальные папки не проверяются. В боевом режиме ошибки собираются,
  а обработка продолжается.
- **Числовые префиксы случайны.** Тесты проверяют формат `NNNN `, диапазон и
  уникальность, а не конкретные числа; перед сравнением имён префикс
  снимается (`helpers.strip_prefix`).
- **Золотые значения** (`helpers.py`: `NAMES_CASES`, `LANG_CASES`,
  `SANITIZE_CASES`, `TRANSLIT_CASES`, `TABLE_SPOT`, `TABLE_SIZES`) сняты с
  версии, которая была побайтово сверена с исходным однопитонным файлом.
  Если поведение меняется намеренно — обновляйте эти таблицы вместе с кодом.
- Тесты не сравниваются с «оригиналом» из git: единственная страховка —
  эти золотые значения плюс сквозные CLI-прогоны.
- `conftest.py` сам добавляет `translit/public` и каталог тестов в
  `sys.path` и регистрирует маркер `gui`, поэтому набор работает и вне
  корня репозитория (например, на скопированной папке).
