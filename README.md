# Обработка mp3-файлов для китайских магнитол

С автомагнитолами есть две проблемы:

#### 1. Поддержка русских букв в названиях песен

Многие китайские автомагнитолы, даже современные (на момент конца 2025 г.) и продвинутые, совершенно не воспринимают кириллицу в именах файлов. То есть, при записи файлов с русскими именами на флэшку, магнитола их просто не видит. И кириллические папки не видит. И тэги внутри mp3-файлов.

И если для 1-DIN магнитолы это не очень большая проблема, достаточно переименовать все файлы во что-то вроде 001.mp3, 002.mp3 - всё равно на маленьком экранчике имена песен не показываются, то вот на большом экране хотелось бы видеть что-то более информативное.

#### 2. Отвратно реализованный случайный выбор песен

Кажется, что это мелочь, пока не задолбает.

На одной модели, современной, с большим сенсорным экраном и кучей настроек, рандом был реализован настолько своеобразно, что несколько одних и тех же песен проигрались по нескольку раз с вкраплениями других песен.

На другой магнитоле, тоже современной китайской с ещё более крутым экраном, при включении-выключении сбрасывалась опция случайного выбора треков. Каждый раз при повороте ключа плеер начинал играть файлы по порядку, как на старых кассетных плеерах. Постоянно не забывать об этом и вынужденно лезть в настройки быстро начало раздражать.

## Описание скрипта

Вот для решения проблем с русским языком и/или кривым случайным выбором песен и был написан этот скрипт.
Он умеет:
  - **автоматически быстро и массово транслитерировать имена файлов в папке**. Отдельно обрабатываются русский, украинский, польский, болгарский, немецкий языки - у каждого из них есть свои особенности. У прочих европейских языков диакритические символы преобразуются в обычные латинские (è -> e), этого достаточно.
  - **транслитерировать ID3-тэги внутри этих файлов**. Позволяет магнитоле показывать имя песни и исполнителя, пусть и в таком урезанном виде.
  - **добавлять к именам файлов и перегенерировать числовые префиксы**. Такой некий искусственный рандом, чтобы после каждого поворота ключа зажигания каждый раз не лазить в меню магнитолы и включать случайный выбор.

Отдельно расширена обработка декоративных символов Unicode - на основе множества встреченных "в дикой природе" имён файлов. "ᗰყᎼӹӄค•ϐ•ᗰคᏇนਮყ", вот это всё. Не идеально, но такой цели и не ставилось, главное, что магнитола увидит.

Теги, после их переименования остаются совершенно валидными, Winamp, AIMP, MP3tag их без проблем читают. Картинки альбомов тоже остаются на месте (технически это тоже теги).

## Установка ##

Для работы скрипта нужны:
  - Python 3. Качается с официального сайта: https://www.python.org/downloads/ и устанавливается очень просто, Далее-Далее-Далее-Готово.
  - модуль mutagen для работы с ID3-тегами в mp3-файлах. Для установки достаточно написать pip install mutagen в консоли Python
  - ну и сам скачанный этот скрипт music_transliterate.py

## Использование ##

Изменение имён и тегов файлов проще всего делать на самой флэшке, после копирования файлов на неё. Не забывайте, что если направите переименование на свою коллекцию, откат вам придётся делать вручную. Чтобы этого избежать, лучше сразу работать только с копиями mp3-файлов на флэшке.

**Запуск:**<br>
python music_transliterate.py <путь_к_папке>

Тут обратите внимание, что в Windows разделитель пути - обратный слэш \ , а в Python используется прямой / . Как вариант, можно задублировать обратные слэши ( \ -> \\\\ )<br>

То есть, для запуска на флэшке в папке D:\Music\ вы даёте команду:<br>
**python music_transliterate.py D:/Music/**<br>
Ну и помните, что папку на флэшке надо называть без русских букв, иначе магнитола вообще не увидит такую папку, всю целиком.

Для запуска в папке Music локального сервера с именем server1:<br>
**python music_transliterate.py //server1/Music**

Для обновления псевдослучайных числовых префиксов - всё то же самое.

Есть дополнительные параметры:<br>
--only-prefixes      : Только добавить/изменить префиксы (без транслитерации) - полезно для перегенерации префиксов на флэшке<br>
--only-transliterate : Только транслитерировать (без добавления префиксов)<br>
--testonly           : Только пройтись по папке (в отличие от обычного режима, и по всем вложенным) и проверить, что всё ок
    
**Тестирование:**<br>
Для тестирования добавлен параметр testonly - в отличие от обычного запуска, проходит по вложенным папкам. Ничего не трогая, смотрит, не споткнется ли на каком-то файле. При ошибке выдаёт подробную диагностику.

Чтобы запустить с флагом testonly можно добавить его в sys.argv перед вызовом main.<br>
**sys.argv.append('--testonly')**

Либо же добавить его в командную строку при вызове<br>
**python music_transliterate.py D:/Music/ --testonly**<br>
